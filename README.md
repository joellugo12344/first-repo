# 🔐 Password Strength Checker

A Python-based password security tool that analyzes password strength and provides improvement suggestions.

## 📌 Features

- Checks password length
- Detects uppercase letters
- Detects lowercase letters
- Checks for numbers
- Checks for special characters
- Calculates a security score
- Provides password improvement tips
- Generates secure passwords

## 🛠️ Technologies Used

- Python 3
- Regular Expressions
- Secrets Module
- String Processing
